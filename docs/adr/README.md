# Architekturentscheidungen (ADR)

Eine ADR (Architecture Decision Record) hält eine wichtige Entscheidung über den Aufbau des Systems
fest. Jede Entscheidung steht in einer eigenen Datei. Darin steht auch, welche Alternative erwogen
wurde und welchen Preis die gewählte Lösung hat. Die Liste aller Entscheidungen mit Kurztitel steht
in [../12-entscheidungen.md](../12-entscheidungen.md). Begriffe des Projekts erklärt das
[Glossar](../glossar/glossar.md).
