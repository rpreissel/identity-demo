# Lebenszyklus, unabhängig vom Intent

Die Zustände eines Intents beschreiben den Weg durch die Journey, also welcher Schritt gerade an
der Reihe ist. Der Lebenszyklus (`JourneyLifecycle`) sagt dagegen nur, ob die Journey noch läuft,
pausiert oder beendet ist. Das Diagramm dazu steht im Domänenmodell:
[02-domaenenmodell.md](../02-domaenenmodell.md) Abschnitt 3, „Lebenszyklus der AuthJourney“.
