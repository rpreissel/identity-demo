# Lebenszyklus, unabhängig von der Journey

Die Zustände einer Journey beschreiben ihren Weg, also welcher Schritt gerade an der Reihe ist.
Der Lebenszyklus (`JourneyLifecycle`) sagt dagegen nur, ob ein Durchlauf (`AuthJourney`) noch läuft,
pausiert oder beendet ist. Das Diagramm dazu steht im Domänenmodell:
[02-domaenenmodell.md](../02-domaenenmodell.md) Abschnitt 3, „Lebenszyklus der AuthJourney“.
